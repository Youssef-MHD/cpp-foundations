# C++ Foundations — Part 1

## 📚 About This Part

This repository contains my notes, exercises, and solutions from Part 1 of the C++ Foundations track on Programming Advices.

I am learning C++ as the foundation of a broader software-development journey. The goal of the program is not only to learn one programming language, but to build a strong understanding of programming and backend development concepts that can later be applied across different technologies and platforms.

The overall learning path covers backend development for:
* 📱 Mobile applications
* 🖥️ Desktop applications
* 🌐 Web applications

The program is organized into 24 courses, starting with C++ to establish fundamental programming concepts before moving on to technologies such as C# and other backend-development topics.

## 🎯 Why C++?

C++ is being used as the foundation because it provides a strong understanding of how programming works at a deeper level.

Through C++, I am learning concepts such as:
* Variables and data types
* Operators
* Conditions
* Loops
* Functions
* Arrays
* Strings
* Structures
* Pointers
* Memory
* Object-oriented programming
* Problem solving
* Writing clean and organized code

These concepts are important because they are not limited to C++. They provide a foundation that can make learning other programming languages and technologies easier later.

## 🧠 What I Am Learning

Part 1 focuses on building the fundamentals required to become comfortable with programming.

### Core Programming Concepts
* Understanding how programs work
* Writing and compiling C++ programs
* Variables and constants
* Input and output
* Arithmetic and logical operations
* Conditional statements
* Loops
* Functions
* Arrays and strings
* Basic problem solving

### Problem Solving
A major part of this stage is learning how to approach programming problems. Instead of only memorizing syntax, I am practicing how to:
1. Understand the problem.
2. Break it into smaller parts.
3. Determine the required inputs and outputs.
4. Design a solution.
5. Implement the solution in C++.
6. Test the program.
7. Fix errors and improve the solution.
